# Synthetic CPC Cases

This folder contains a small set of **fully synthetic** clinicopathological conference (CPC)
cases written in the style of the *New England Journal of Medicine* (NEJM) CPC series. They are
provided as the default, openly redistributable dataset for SDBench so that the benchmark runs
out of the box without access to any restricted clinical data.

> **Note:** These cases are **not** suitable for reporting actual diagnostic performance. They are
> provided as an initial *train* set for testing and developing agents.
> Any real-world or comparative performance — with the baseline agent
> or any other agent — should be measured on the NEJM, MIMIC, or another clinically sourced dataset,
> not on these synthetic cases.

## How these cases were created

- A clinician worked with **Claude Opus 4.8** to author each case. The clinical
  content — presentation, history, examination, laboratory and imaging findings, hospital course,
  discussion, and final diagnosis — is **entirely synthetic** and generated by Claude Opus. It
  does not correspond to any real patient.
- **Gemini 3.1 Pro** and **GPT-5.5** were then used to independently verify the internal
  consistency and clinical plausibility of each case.
